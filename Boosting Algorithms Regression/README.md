# Boosting Algorithms for Regression

## 📌 Objective
To implement and compare boosting-based regression algorithms for predicting insurance charges.

## 📂 Project Structure
- **PPTs/**  
  Presentation slides explaining:
  - AdaBoost Regression
  - XGBoost Regression
  - LightGBM Regression

- **Codes/**  
  Python implementations of:
  - AdaBoost Regressor
  - XGBoost Regressor
  - LightGBM Regressor

## 🧠 Algorithms Used
- AdaBoost Regression
- XGBoost Regression
- LightGBM Regression

## 📊 Dataset
Insurance dataset with features:
- Age
- BMI
- Children
- Sex
- Smoking status

Target variable:
- Insurance charges

## 📈 Evaluation Metric
- R² Score

## 🏁 Conclusion
Boosting algorithms improved prediction performance.
LightGBM and XGBoost achieved higher R² scores compared to AdaBoost.

- Python
